Referencia del navegador

Atajos de teclado

Combinaciones disponibles para navegar y controlar el navegador.

Navigation

  • Ctrl/Cmd+LFocus the address bar
  • Ctrl/Cmd+[ / Ctrl/Cmd+]Go back / forward
  • Ctrl/Cmd+HShow history

Tabs

  • Ctrl/Cmd+TOpen a new tab
  • Ctrl/Cmd+WClose the current tab
  • Ctrl/Cmd+Shift+TReopen the last closed tab
  • Ctrl/Cmd+Tab / Ctrl/Cmd+Shift+TabSelect the next / previous tab
  • Ctrl/Cmd+1–8Select tab 1–8
  • Ctrl/Cmd+9Select the last tab

Page

  • Ctrl/Cmd+R / F5Reload the page
  • Ctrl/Cmd+Shift+RReload ignoring cache
  • Ctrl/Cmd+PPrint the page

Window and view

  • F11Toggle fullscreen
  • Ctrl/Cmd+plus/equal / minus / 0Zoom in / out / reset

Bookmarks

  • Ctrl/Cmd+DAdd or remove a bookmark
  • Ctrl/Cmd+Shift+BToggle the bookmarks bar

Developer

  • Ctrl/Cmd+Shift+I / F12Toggle developer tools
